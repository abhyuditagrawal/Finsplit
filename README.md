# 💰 FinSplit - Expense Tracking & Splitting App

A full-stack expense tracking and splitting application with AI-powered spending predictions.

## ✨ Features

- 📊 **Expense Tracking** - Track personal and group expenses
- 🔀 **Expense Splitting** - Split bills with friends and groups
- 👥 **Group Management** - Create and manage expense groups
- 🎯 **Budget Tracking** - Set and monitor category-based budgets
- 🔮 **AI Predictions** - ML-powered spending forecasts using Facebook Prophet
- 📈 **Analytics Dashboard** - Visualize spending patterns with charts

## 🛠️ Tech Stack

### Frontend
- HTML5, CSS3, JavaScript
- Chart.js for data visualization

### Backend
- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication
- bcrypt for password hashing

### ML Service
- Python + Flask
- Facebook Prophet for time series forecasting
- Pandas & NumPy for data processing
